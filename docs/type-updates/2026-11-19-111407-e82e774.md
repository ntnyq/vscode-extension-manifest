## Individual changes

### 1. `ExtensionContributes.chatResources` and `ExtensionChatResource`

Previously absent. The public type now accepts an array of entries with string `id`, `label`, and `resource`, an optional string `icon`, and optional `mode` of `pinned` or `aboveInput`. The resource string can interpolate `${chatSessionId}` and `${agentSessionId}`. VS Code validates entries, converts the icon to a theme icon, and lists each resource while it exists. The handler requires `contribChatResources`. This is additive. Regressions cover both modes, a minimal entry, a missing resource, an unsupported mode, and a non-array contribution. [Schema and registration](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/browser/chatResources/chatResourceContributions.ts#L65-L107), [validation and proposal gate](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/browser/chatResources/chatResourceContributions.ts#L109-L144), [URI template resolution](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/browser/chatResources/chatResourceContributions.ts#L48-L62), [Artifacts pill consumer](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/browser/chatResources/chatResourceContributions.ts#L175-L202).

### 2. `ExtensionMenuKind` title bars

Added `titleBar` and `agents/titleBar` to the exported known-identifier union. Both were already accepted by the open-ended `ExtensionContributes.menus` map used for custom submenu IDs. The registry binds the identifiers to the editor and Agents title bars and requires `contribTitleBar` for both. Code that exhaustively enumerates `ExtensionMenuKind` may need the new members. Regressions cover both identifiers and reject incorrect casing in the known-identifier union. ### 5. `ExtensionLanguageModelChatProvider.icon`

Previously absent. The optional property reuses `ExtensionThemeableIcon`. The schema and resolver accept a theme icon reference, a single relative path, or an object with both `light` and `dark` paths. VS Code resolves paths relative to the contributing extension and ignores malformed icons after warning. The runtime also checks path containment and separators. This addition has no proposal gate. Regressions cover all three forms and reject a light-only object. [Manifest schema](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/common/languageModels.ts#L949-L970), [icon resolver](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/common/languageModels.ts#L1005-L1035), [registration handler](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/src/vs/workbench/contrib/chat/common/languageModels.ts#L1353-L1363), [built-in OpenRouter contribution](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/extensions/copilot/package.json#L1673-L1680).

### 6. `ExtensionMarkdownCodeBlockEditorProvider.presentation`

Previously absent. The optional object has boolean `resizable`, `fullWidth`, and `fullView` and numeric `minHeight` and `maxAutomaticHeight`. Every member is optional. The Markdown extension rejects an invalid presentation and merges the contributed defaults with values returned by a provider. Heights in the interval `(0, 10000]` pass runtime validation. The TypeScript representation uses `number` and documents that limit. This addition has no proposal gate in the manifest reader. The regression accepts a presentation and rejects string heights. [Manifest reader](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/extensions/markdown-language-features/src/markdownExtensions.ts#L174-L213), [presentation validation and merge](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/extensions/markdown-language-features/src/preview/markdownEditorProtocol.ts#L40-L64), [upstream manifest regression](https://github.com/microsoft/vscode/blob/e82e774f0735d47ee7021d34a6055234229cc9b3/extensions/markdown-language-features/src/test/markdownEditorProvider.test.ts#L320-L327).
